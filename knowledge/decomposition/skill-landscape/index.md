# Skill landscape

* [The Agent Skills standard (SKILL.md)](agent-skills-standard.md) - Agent Skills is the portable packaging format for agent instructions; it is a delivery format, not a decomposition method, and its registries carry real supply-chain risk
* [AppLab backlog plugin (refine and nightshift)](applab-backlog-plugin.md) - A tracker-agnostic Claude Code plugin whose refine skill promotes a ticket to READY only when six questions are answered and then stops, leaving the move to the build queue as a person's hand-move; its nightshift half builds unattended
* [BMAD Method ticket tree and readiness gate](bmad-method.md) - BMAD has moved from sharded epics, story files and a separate readiness check (v6) to a Product Owner agent that keeps an initiative-epic-story tree in TOML and markdown, with human-approval flags per entry; it is the most complete model and the fastest-changing
* [CCPM (Claude Code Project Manager) skill](ccpm-project-manager-skill.md) - The most-adopted GitHub-issues-native decomposition skill turns a PRD into an epic and numbered task files with depends_on, parallel and conflicts_with metadata, then syncs them as GitHub sub-issues; it has no story level and no approval gate before it writes
* [GitHub awesome-copilot breakdown-plan (and the github-issues skill)](github-awesome-copilot-breakdown.md) - The GitHub-owned breakdown-plan skill has the fullest Epic-to-Task issue templates, but it models children as checkbox lists and labels; its sibling github-issues skill supplies the native sub-issue, type and blocked-by mechanics
* [Keel backlog-refinement skill](keel-backlog-refinement.md) - A refinement skill that runs INVEST as six pass/fail checks, turns each acceptance criterion into an atomic Gherkin test with a measurable Then, and proposes but never sets the ready state; its storage is a SysML engine, not GitHub
* [Red Hat agile skill (toddward)](red-hat-agile-skill.md) - A text-only Claude skill that best teaches the split between per-story acceptance criteria and a project-wide Definition of Done, with an advocate-challenger-integrator debate per epic; it has no licence, so only its ideas can be borrowed
* [Epic, story and task skills compared (2025-2026)](skill-landscape-comparison.md) - One rubric scores twelve agent skills and tools that decompose or refine work; no single one fits a GitHub-native, agent-run board, so borrow text and gates from five of them and install none
* [timos-claude-code-plugins story-readiness gate and refine-issue](timos-story-readiness-gate.md) - The most GitHub-native readiness gate found in 2026 is a read-only agent that returns READY or NEEDS_REFINEMENT from four checks, including native and acyclic blocked-by edges; its refine-issue skill walks an epic's native sub-issues with a person present
